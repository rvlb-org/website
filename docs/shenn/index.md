# SHENN — نظرة عامة

**SHENN** (Self-Healing Evolutionary Neural Networks) هي شبكة عصبية تحاكي الحياة البيولوجية بكل تعقيداتها.

## الفكرة الجوهرية

تبدأ الشبكة بـ **خلية واحدة فقط** وتنمو تلقائياً حسب تعقيد البيانات — بدون تدخل بشري.

## المزايا الرئيسية

| الميزة | التفصيل |
|---|---|
| **النمو التكيفي** | تنقسم الخلايا تلقائياً عند ارتفاع الخطأ |
| **الجهاز المناعي** | يكتشف ويعزل الخلايا الشاذة |
| **الانتحار الخلوي** | يحذف الخلايا الضارة نهائياً |
| **الأجسام المضادة** | ذاكرة دائمة للأخطاء المكتشفة |
| **الشرنقة والبعث** | تموت وتُولد من جديد محتفظةً بحكمتها |

## البنية

```
SHENN/
├── core/         ← الشبكة والخلايا
├── immune/       ← الجهاز المناعي
├── lifecycle/    ← دورة الحياة
└── memory/       ← الذاكرة الجينية
```

## التشغيل السريع

```bash
git clone https://github.com/enki-core/SHENN-ai.git
cd SHENN-ai
python3 SHENN/main.py
```

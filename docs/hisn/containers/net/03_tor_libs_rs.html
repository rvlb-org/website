مكتبات مخصصة لتمثيل دوائر Tor (Circuits) وتدفقاتها (Streams) بدون استخدام Heap.

1. إدارة الدوائر (tor-circuit)

  • يدعم حتى 3 قفزات (MAX_HOPS = 3: Entry, Middle, Exit).
  • HopLayer: يحمل مفتاح التشفير الأمامي (Kf) ومفتاح فك التشفير الخلفي (Kb) باستخدام ChaCha20.
  • wrap_relay(payload): لتغليف خلية للخروج، تُشفر الخلية من القفزة الأخيرة (Exit) رجوعاً إلى الأولى (Entry) - تأثير البصلة (Onion Layering).
  • unwrap_relay(cell): لفك الخلايا الواردة من الأولى إلى الأخيرة.

2. إدارة التدفقات (tor-stream)

  • يُجرد اتصال TCP ليعمل فوق الـ Circuit بـ API مشابه للـ Sockets العادية (read, write).
  • StreamManager: يدعم حتى MAX_STREAMS = 8 تدفقات متزامنة فوق Circuit واحدة.
  • write(data): يُقسم البيانات الطويلة (مثل طلب HTTP) إلى كتل بحجم أقصاه MAX_CELL_DATA = 498 بايت، ويطلب من الـ Circuit تغليفها كـ Relay Cells جاهزة للإرسال في شبكة Tor.

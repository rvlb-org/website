المسار: containers/tor/src/network.rs

يُوفر بيئة وهمية (Mock Environment) لمكتبة smoltcp، لأن الوصول الفعلي لبطاقة الشبكة (VirtIO-Net/DMA) يحتاج إلى تعريفات أجهزة معقدة جداً غير متوفرة في الإصدار الحالي.

الهياكل:

  • DummyDevice: يُطبّق واجهة smoltcp::phy::Device (MTU: 1500)
  • DummyRxToken: يُرجع 0 بايت كحزم واردة لعدم وجود إنترنت حقيقي
  • DummyTxToken: يستقبل الحزم المرسلة من smoltcp ويضعها في Buffer ليتم تجاهلها بأمان

هذا الملف أساسي لاختبار طبقة Tor / HTTP وبناء دوال الـ Routing، حتى لو لم يتم إرسال البيانات للإنترنت الحقيقي.

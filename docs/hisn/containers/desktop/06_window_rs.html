المسار: containers/desktop/src/desktop_ui/window.rs

يُعرّف هيكل Window الذي يُمثّل نافذة واحدة:

  • x, y, w, h: موقع وأبعاد النافذة الحالية
  • prev_x, prev_y, prev_w, prev_h: الأبعاد قبل التكبير (لاستعادتها عند إلغاء Maximize)
  • title: [u8;32]: عنوان النافذة (يتغير عند فتح ملف)
  • app_name: [u8;16]: اسم التطبيق الداخلي للـ routing ("calc", "files", "editor", "viewer")
  • open, minimized, maximized: bool: حالة النافذة
  • accent: Color: لون التمييز للنافذة

الدوال المُساعدة:

  • in_titlebar(cx, cy): يتحقق أن النقر في شريط العنوان (Y أقل من TITLEBAR_H=28)
  • in_close_btn / in_minimize_btn / in_maximize_btn: حسابات hit-testing لأزرار التحكم

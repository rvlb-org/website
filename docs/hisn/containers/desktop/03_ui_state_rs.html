المسار: containers/desktop/src/desktop_ui/mod.rs

يُعرّف UIState — الهيكل المركزي الذي يحمل كامل حالة سطح المكتب في مكان واحد. الحقول الرئيسية:

  • windows: [Window; MAX_ICONS] — النوافذ المفتوحة
  • icons: [DesktopIcon; MAX_ICONS] — أيقونات الـ Dock السفلي
  • calc_state, files_state, editor_state, viewer_state — حالة كل تطبيق مدمج
  • desktop_fs: FilesBackend — نسخة مخصصة لجلب ملفات /home/user/Desktop
  • zorder: ZOrderStack, focus: FocusManager, taskbar_mgr: TaskbarManager — وحدات WM
  • drag: DragState — حالة السحب والإفلات الحالية

الدوال الرئيسية:

  • init(ptr): يُهيئ الهيكل مباشرة في static storage. يقرأ PROGRAM_REGISTRY ويستخرج أسماء التطبيقات وبكسلاتها لبناء الأيقونات. عنوان كل حزمة SVP = offset سابق + 1088 + elf_size.
  • on_press(cx, cy): يتحقق بالترتيب: Taskbar → Dock → نوافذ (Z-Order) → ملفات Desktop → Titlebar drag → أيقونات. يُوجّه النقر للـ handler الصحيح.
  • on_drag(cx, cy): يُطبّق DragTarget — يُحرّك النافذة أو الأيقونة أو Scrollbar حسب النوع.
  • on_key(ch): يُوجّه للتطبيق المُركَّز (focused) فقط.
  • handle_pending_open(): يفتح ملفاً بالبرنامج المناسب (editor للنصوص، viewer للصور) عبر open_file() / open_image() ويُحدّث عنوان النافذة في Taskbar.

الدالتان:

  • render(fb, state, zstack): رسم كامل الشاشة — تُستدعى عند أي تغيير يؤثر على الشاشة كلها
  • render_window(fb, state, window_id): رسم نافذة واحدة فقط — تُستدعى عند Scrollbar drag أو Hover داخل نافذة لتجنب إعادة رسم الكل وتقليل وميض الشاشة

المسار: containers/desktop/src/desktop_ui/draw.rs

يحتوي على دوال رسم جميع عناصر الواجهة على الـ Framebuffer مباشرة. الدوال الرئيسية:

  • draw_topbar_pub(fb): يرسم الشريط العلوي بلون 0x1A1A2E مع تأثير تدرج لوني ناعم
  • draw_taskbar_pub(fb, state): يرسم الشريط السفلي المحمي (Always On Top) بارتفاع TASKBAR_H=48px مع أزرار التطبيقات المفتوحة
  • draw_dock_only(fb, state): يرسم Dock مركزي في الأسفل — يحسب العرض الكلي ديناميكياً: total_w = start_btn(60) + 8 + n_apps×44 + gaps×10 + 16
  • draw_desktop_files_pub(fb, state): يرسم ملفات /home/user/Desktop كأيقونات 48×56px على اليمين، يتجاهل ملفات .vlk (تُظهر كأيقونات برامج)
  • draw_start_menu_pub(fb, state): يرسم قائمة Start كـ Panel شفاف فوق الـ Dock
  • PROGRAM_REGISTRY: البيانات الثنائية لكل تطبيقات SVP مدمجة مباشرة في الكود

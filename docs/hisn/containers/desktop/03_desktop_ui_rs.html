الوحدة الأكبر والأكثر تعقيداً في النظام. تحتوي على هيكل UIState الذي يُدير الحالة الكاملة لسطح المكتب. تتضمن وحدة draw.rs دوال رسم جميع عناصر الـ UI (شريط المهام، النوافذ، الأيقونات، القوائم)، وwindow.rs للتعامل مع فتح وإغلاق النوافذ، وdrag.rs لآلية السحب والإفلات، وwm/ لـ Window Manager (Z-Order, Focus, Compositor).

المسار: containers/bus/src/main.rs

يحتوي على حلقة server.serve() الكاملة. يُصنّف كل رسالة واردة حسب MessageTag:

أ) عمليات الملفات المباشرة — يُمرّرها مباشرة لـ FS_Vault عبر forward_to_fs():

  • CreateFile / WriteFile
  • DeleteFile / DeleteDir
  • ReadFile
  • CreateDir / ListDir

ب) العمليات المركّبة — مُنفَّذة داخل Bus_Vault:

  • CopyFile: خطوتان — ReadFile(src) → WriteFile(dst). إذا فشلت القراءة يُعيد Err دون الكتابة.
  • MoveFile: ثلاث خطوات — CopyFile → DeleteFile(src). الحذف يحدث فقط إذا نجح النسخ.

ج) اختصارات سطح المكتب:

  • CreateShortcut: يُنشئ ملف .vlk في /home/user/Desktop/ عبر WriteFile
  • DeleteShortcut: يحذف ملف .vlk عبر DeleteFile
  • RegisterApp: يكتب ملف التطبيق في /home/user/apps/

د) الحافظة (Clipboard) — مُخزَّنة في ذاكرة Bus_Vault كـ static mut CLIPBOARD: [u8; 256]:

  • ClipboardCopy: ينسخ req.payload[..len] إلى CLIPBOARD
  • ClipboardPaste: يُعيد CLIPBOARD[..CLIPBOARD_LEN] في رسالة الرد
  • ClipboardClear: يُصفّر المصفوفة ويُعيد CLIPBOARD_LEN=0

هـ) الشبكة (مستقبلاً):

  • NetConnect / NetRequest: يُقرّ الطلب حالياً دون توجيه — Placeholder لتوصيل Tor_Vault في slot 3 لاحقاً

الدالة الداخلية forward_to_fs(req, ipc_buf): تُنشئ Sender مؤقتاً باستخدام FS_EP_CAP=1 وتُرسل الطلب وتنتظر الرد عبر send_recv().

المسار: containers/init/src/input_vault_setup.rs

يُمثّل هذا الملف مسؤولية حاوية init في تجهيز وبناء حاوية input_vault مع صلاحيات العتاد اللازمة (Capability injection). هذه هي الخطوة التي تسمح لـ Input Vault بالتعامل مع العتاد الفيزيائي في وضع المستخدم.

الخطوات الرئيسية:

  1. تخصيص الـ IOPort (PS/2):
    • يُستخدم seL4_X86IOPortControlIssue لتفويض صلاحيات القراءة والكتابة للمنافذ من 0x60 إلى 0x64 (منافذ PS/2).
    • تُوضع هذه الصلاحية في SLOT_IOPORT (رقم 1) في CNode الخاص بـ Input Vault.
  2. إعداد المقاطعات (IRQs) عبر IOAPIC:
    • الكيبورد (IRQ 1): يُستخدم seL4_IRQControl_GetIOAPIC مع Pin 1 و Vector 33 (32 + 1).
    • الماوس (IRQ 12): يُستخدم نفس الاستدعاء مع Pin 12 و Vector 44 (32 + 12).
    • الصلاحيات توضع في SLOT_KBD_IRQ و SLOT_MOUSE_IRQ.
  3. ربط الـ Notifications:
    • يتم إنشاء NotificationObject وصنع نسختين منه (Minting) مع Badges مختلفة: BADGE=1 للكيبورد، BADGE=2 للماوس.
    • يُستخدم seL4_IRQHandler_SetNotification لربط مقاطعة العتاد بهذه الكائنات، بحيث عندما تحدث المقاطعة، يُرسل الـ Kernel إشعاراً للحاوية يحمل الـ Badge المناسب.

بدون هذا الملف، لا تستطيع حاوية input_vault قراءة المنافذ أو استقبال أي مقاطعة، وستتعرض لـ Fault من Kernel النظام.

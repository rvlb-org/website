المسار: containers/fs/src/disk_writer.rs

يُنفّذ التخزين المستمر (Persistence) عبر تواصل Zero-Copy مع Disk_Vault. يستخدم صفحة الذاكرة المشتركة عند العنوان الثابت 0x600000 (4KB) كـ Buffer مشترك.

نظام التخزين — تنسيق القطاع 0 (Root Directory Index):

| المحتوى           | الحجم    |
|-------------------|----------|
| path (full path)  | 64 bytes |
| sector (LBA)      | 4 bytes  |
| file_size         | 4 bytes  |
| ... (تكرار)       | 72 bytes |
(يسع القطاع الواحد حتى 7 ملفات: 7 × 72 = 504 بايت)

الدالتان:

  • flush_to_disk(fs, ipc_buf):
    • يكتب فهرس الجذر في LBA 0 عبر الذاكرة المشتركة + MessageTag::WriteSector
    • لكل ملف: يضع بياناته (512 بايت) في الذاكرة المشتركة ثم يُرسل WriteSector(lba=e.sector) لـ Disk_Vault
    • يُستدعى تلقائياً بعد كل عملية تعديل (Delete, Rename, Write, Mkdir)
  • load_from_disk(fs, ipc_buf):
    • يقرأ LBA 0 أولاً — إذا كان الـ byte الأول 0 فالقرص فارغ (يُعيد false)
    • يُكرّر على السجلات (كل 72 بايت) ويقرأ بيانات كل ملف من قطاعه
    • يُحدّث fs.next_sector ليكون max(current, last_sector + 1) لمنع الكتابة فوق بيانات موجودة
    • يُعيد true إذا تم تحميل ولو ملف واحد

الثوابت: DISK_EP_CAP=1 (Endpoint الـ Disk_Vault في CNode الـ FS)، SECTOR_SIZE=512.

المرحلة الأخيرة من تهيئة الحاوية: ربط الذاكرة المشتركة وتشغيل الـ Thread.

  • map_shared_memory(): يُنشئ صفحة 4KB مشتركة (Dataport/Shared Memory):
    • يربطها في VSpace الـ init عند 0x801000
    • ينسخ الـ Frame Capability بـ seL4_CNode_Copy
    • يربط النسخة في VSpace الحاوية الجديدة عند 0x5F0000
    • النتيجة: كلا الطرفين يكتبان ويقرآن من نفس الصفحة الفيزيائية بدون IPC
  • configure_and_start_tcb(): يُجهّز الـ Thread ويُشغّله:
    • seL4_TCB_Configure: يربط الـ TCB بـ (CNode + VSpace + IPC Buffer Frame + Fault EP)
    • cspace_root_data = 52: عمق CNode الجديد (2^12 = 4096 slot) مُرمَّز كـ Guard
    • seL4_TCB_WriteRegisters (count=20): يكتب كل السجلات:
      • rip = entry point
      • rsp = stack top (0x421000)
      • rdi = IPC Buffer vaddr (arg0 للـ _start)
      • rsi = 0 (Endpoint في slot 0 من CNode الجديد دائماً)
      • rflags = 0x202: IF=1 (المقاطعات مُفعَّلة) + Reserved bit
    • الـ resume=true في WriteRegisters يُشغّل الـ Thread فوراً بعد الكتابة

حاوية init هي الـ Root Task — أول كود يعمل في مساحة المستخدم (User-space) بعد إقلاع نواة seL4. النواة تُعطيها كل الصلاحيات الابتدائية (Capabilities) والذاكرة الخام (Untyped Memory) عبر هيكل seL4_BootInfo، ثم تتقاعد عن التدخل المباشر.

مسؤوليات init تنقسم لمرحلتين:

  • مرحلة الإقلاع (Bootstrap): تُنشئ وتُشغّل الحاويات التسع بالترتيب الصحيح، وتُوزّع عليها المفاتيح (Endpoints) التي تحتاجها للتواصل. ترتيب الإقلاع: Crypto_Vault → Tor → Disk_Vault → FS_Vault → Auth_Vault → Bus_Vault → Desktop → Input_Vault → Programs.
  • مرحلة التشغيل (Runtime): تتحوّل إلى Program Manager — تستمع على launch_ep لطلبات تشغيل التطبيقات من حاوية Desktop، وتُنشئ مساحة عزل جديدة لكل تطبيق.

كل حاوية تُحمَّل كـ ELF ثنائي مدمج مباشرة في init عبر include_bytes! — صفر تبعيات على نظام ملفات وقت الإقلاع.

setup_crypto_vault() — نموذج قياسي لكيفية تشغيل أي حاوية من init. الخطوات الست:

  1. CNode: seL4_CapTableObject, size_bits=12 → جدول صلاحيات بـ 2^12 = 4096 فتحة
  2. TCB: seL4_TCBObject, seL4_TCBBits → Thread Control Block
  3. VSpace: seL4_X64_PML4Object → جذر هرم الـ Paging الجديد
  4. IPC Buffer Page: seL4_X86_4K → صفحة الـ IPC Buffer المُخصَّصة
  5. Endpoint في CNode الحاوية: retype_object_in_cnode(seL4_EndpointObject, slot=0, cnode) — يُنشئ الـ Endpoint مباشرة في slot 0 من CNode الحاوية الجديدة (هكذا تجد الحاوية endpoint بدون تمريره)
  6. نسخ الـ Endpoint إلى init: seL4_CNode_Copy(src=cnode/slot0 → dst=init_cnode/alloc_slot, depth=12, rights=0xF) — حتى تستطيع init إرسال رسائل للحاوية

قيمة rights=0xF = كل الصلاحيات (Read + Write + Grant + GrantReply). الـ scratch_vaddr=0x800000 ثابتة لـ Crypto_Vault.

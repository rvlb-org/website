يُدير عملية تحميل وتشغيل التطبيقات الديناميكية (SVP Packages) من ملف manifest.bin المدمج في PROGRAM_REGISTRY. الدوال الرئيسية:

  • load_programs(): يُكرّر على RegistryIter ويستخرج كل حزمة SVP ويشغّلها. يُعيد عدد البرامج المُحمَّلة بنجاح.
  • setup_program(): الدالة الجوهرية — تُنشئ لكل برنامج مساحة عزل كاملة:
    • seL4_CapTableObject (12-bit) → CNode جديد
    • seL4_TCBObject → Thread Control Block
    • seL4_X64_PML4Object → Virtual Address Space
    • seL4_X86_4K → IPC Buffer Page
    • seL4_EndpointObject في slot 0 من CNode الجديد → نقطة تواصل البرنامج
    • نسخ الـ Endpoint إلى CNode الخاص بـ init عبر seL4_CNode_Copy لتتمكن init من الوصول إليه
    • عنوان Scratch فريد لكل برنامج: 0x900000 + (prog_id * 0x100000) لمنع التعارض
  • launch_app_by_name(): تبحث عن الاسم المطلوب في الـ Registry وتُشغّله فوراً عند طلب Desktop، مع استخدام offset فريد 0x80 + idx للـ Scratch.

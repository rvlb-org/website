المسار: libs/security-policy/src/lib.rs

مكتبة مشتركة تُعرّف نظام الـ Badges. تُستخدم من قِبل Auth_Vault (لإصدار الـ Badges) وFS_Vault (للتحقق منها).

هيكل PolicyBadge:

  • app_id: u16 — هوية التطبيق
  • permission: u8 — (0=None, 1=ReadOnly, 2=ReadWrite)
  • path_hash: u32 — FNV-1a hash للمسار المسموح به

ترميز الـ Badge كـ 64-bit Word (to_badge_word):

bit[63:48] = app_id   (16 bits)
bit[47:40] = permission (8 bits)
bit[39:32] = (غير مستخدم)
bit[31:00] = path_hash  (32 bits)

دالة hash_path(path): خوارزمية FNV-1a 32-bit:

  • تبدأ بـ hash = 0x811c9dc5 (FNV offset basis)
  • لكل بايت: hash = (hash XOR byte) × 0x01000193 (FNV prime)

hash_path("/home/user") يُعطي نفس القيمة دائماً — يجب أن يتطابق بين ما تُصدره Auth_Vault وما تتحقق منه FS_Vault لقبول الطلب.

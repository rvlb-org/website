حاوية Auth_Vault هي مصدر الثقة الأمني الوحيد في النظام. وظيفتها محددة وحرجة: تُولّد تذاكر أمان (Security Tokens) للتطبيقات التي تحتاج الوصول لنظام الملفات. تعمل كـ Trusted Authority يُصدر عملات أمان مُشفَّرة لا يمكن تزويرها.

مبدأ العمل:

  1. يطلب التطبيق (مثل Desktop) تذكرة من Auth_Vault مُرسِلاً cmd=0x100 و app_id
  2. تُولّد Auth_Vault PolicyBadge يحمل: الصلاحية + hash المسار المسموح
  3. يُرسَل الـ Badge كرقم 64-bit في reply.mr[1]
  4. يستخدم التطبيق هذا الرقم في كل طلب لـ FS_Vault التي تتحقق منه

خريطة Capability Slots: Slot 0 = Own Endpoint، Slot 1 = FS_Vault Endpoint (لحفظ سجلات الأمان مستقبلاً).

**تاريخ الإنجاز:** 2026-07-05 — 17:35 GMT+3

**التصنيف:** GUI / Windows / Dynamic Features

تم استبدال النوافذ الثابتة (مثل Secure Terminal وغيرها) بنظام توليد النوافذ ديناميكياً لتتوافق مع أسماء البرامج المكتشفة في سجل `manifest.bin`. تم تغيير هيكلة `Window` لتقبل مصفوفة `[u8; 32]` كاسم لعنوان النافذة بدلاً من الـ `&'static str`. وبناءً على ذلك، أصبحت الأيقونات عند النقر عليها تفتح نافذة تحمل اسم التطبيق المعني المجمّع ديناميكياً، مع دعم ظهور أي نافذة يتم إضافتها في سجل البرامج، مما يجعل بيئة الـ Desktop مكتملة المرونة وقابلة للتمدد بشكل تلقائي.

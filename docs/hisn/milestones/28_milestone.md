**التصنيف:** File System / Architecture / Containers

تم تأسيس **حاوية نظام الملفات (FS_Vault)** لتكون المسؤولة الوحيدة والمعزولة عن عمليات القراءة والكتابة، تطبيقاً لمبادئ العزل في seL4. تم برمجة نظام ملفات في الذاكرة (**RamFS**) مبدئي يدعم إنشاء مجلدات وملفات وقراءتها/كتابتها. تقوم الحاوية عند الإقلاع بإنشاء الشجرة الأساسية (`/sys`, `/lib`, `/user/apps`, `/user/security`) وكتابة بعض ملفات النظام الأساسية وهمياً. تم دمج حاوية `FS_Vault` مع سكريبتات البناء `compile.sh` لتُجمع وتضاف كـ `FS_VAULT_ELF` في حاوية الـ `Init` وتُشغل أثناء إقلاع النظام لتستمع لطلبات الـ IPC لاحقاً.

**تاريخ الإنجاز:** 2026-07-04 — 00:27 GMT+3

**التصنيف:** GUI / Desktop / Dynamic UI

تم ربط **قائمة ابدأ (Start Menu)** في واجهة سطح المكتب بنظام الحزم الديناميكي بدلاً من القائمة الثابتة المكتوبة يدوياً. الآن عند الضغط على زر Start، تقوم الواجهة بقراءة `manifest.bin` مباشرة عبر `RegistryIter` وتعرض كل برنامج مثبت بشكل ديناميكي. كما تم إعادة تصميم القائمة بالكامل لتصبح ذات طابع **Windows-style منسدلة للأعلى** مع: هيدر أزرق يعرض "seL4-Vault Apps"، وأيقونات ملونة لكل برنامج، وفاصل بين التطبيقات وأزرار النظام (Settings / Lock System / Reboot). علاوة على ذلك تم إصلاح إحداثيات النقر (hit-testing) في `mod.rs` لتتطابق مع الرسم الفعلي لزر Start والأيقونات.

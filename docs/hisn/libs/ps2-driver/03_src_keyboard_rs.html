محرك لوحة المفاتيح. يحتوي على خريطة مفاتيح (Keymap) افتراضية (US QWERTY Scan Code Set 1) مع دعم حالة المفاتيح المُعدّلة (Shift, Caps Lock, Ctrl). تُنفذ process_scancode() التي تحول حزم الـ Scan Codes الخام الواردة من المنفذ 0x60 إلى أحرف ASCII صحيحة قابلة للاستخدام، وتدعم اختصارات لوحة المفاتيح عبر أزرار التحكم.

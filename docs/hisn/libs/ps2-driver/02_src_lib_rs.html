البوابة الرئيسية التي تتفاعل مع العتاد الحقيقي. تُعرّف منافذ PS/2 الثابتة (0x60 و 0x64) وتُغلف عمليات القراءة والكتابة للمنافذ عبر noop_read و noop_write باستخدام seL4_Call. تحتوي على هيكل Ps2Controller الذي يُدير تهيئة وحدة التحكم، وتفعيل جهاز الماوس الإضافي (Auxiliary Device)، ومسح الحزم القديمة (Flush) قبل تفعيل مقاطعات العتاد (IRQs).

ipc-sync — قنوات التخاطب الآمنة بين الحاويات مكتبة تُغلِّف استدعاءات seL4 IPC الخام في واجهات Rust نظيفة وآمنة. تتيح للحاويات التحدث مع بعضها عبر نموذجَي التخاطب: - **`Channel`**: قناة ثنائية الاتجاه تُرسل وتستقبل `IpcMessage` - **`Sender` / `Receiver`**: قناة أحادية الاتجاه #التصميم المعماري: ```text init ──[send]──► endpoint ──[recv]──► crypto_vault init ◄─[recv]── endpoint ◄─[send]── crypto_vault ``` #حجم الرسالة: seL4 يدعم نقل 4 كلمات (MR0..MR3) مباشرةً عبر السجلات. لإرسال بيانات أكبر، تُستخدم الـ IPC Buffer المشتركة.

الملف الوحيد في المكتبة ويحتوي على كامل التنفيذ. يُعرّف حوض ذاكرة ثابت بحجم 256KB (في قطاع BSS) وهيكل BumpAllocator الذي ينفذ الواجهة القياسية GlobalAlloc مما يجعله متوافقاً مباشرة مع #[global_allocator] في Rust. دالة alloc تنفذ المحاذاة (Alignment) بحساب bitwise آمن وترجع null عند امتلاء الحوض. دالة dealloc فارغة عمداً — التحرير يتم عبر reset() التي تُعيد المؤشر إلى الصفر مرة واحدة لتحرير الحوض بأكمله.

حقل جالوا GF(2^8) — الرياضيات الأساسية لـ Shamir GF(2^8) هو حقل محدود (Finite Field) يحتوي على 256 عنصر (0..=255). الجمع فيه = XOR، والضرب يتم بمتعدد الحدود القياسي لـ AES: x^8 + x^4 + x^3 + x + 1 الحد القياسي لـ GF(2^8) المستخدم في AES و Shamir = x^8 + x^4 + x^3 + x + 1 = 0x11b (نحذف البت الأعلى لأنه ضمني)

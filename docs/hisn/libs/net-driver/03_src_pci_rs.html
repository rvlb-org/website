يُعرّف PciDevice الذي يمثل بطاقة شبكة VirtIO وجدت في الناقل (Bus/Slot/Func + BAR0 + Capability). تحتوي PciBus على دالة scan_virtio_net() التي تمسح الـ PCI bus بحثاً عن الـ Vendor ID الخاص بـ VirtIO (0x1AF4) وDevice ID الخاص ببطاقة الشبكة (0x1000). ملاحظة: read_config32 هيكل أولي (Stub) يحتاج للربط مع Capability لمنافذ PCI الخاصة (0xCF8-0xCFC).
